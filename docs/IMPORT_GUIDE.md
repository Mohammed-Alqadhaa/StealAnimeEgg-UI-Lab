# Import Guide

> **ROBLOX STUDIO VISUAL VERIFICATION: NOT PERFORMED.**
> The package was produced and validated in a cloud container without Roblox Studio
> (see `VISUAL_REVIEW.md` for exactly what *was* verified). Please follow the steps below
> and report anything that looks different from `docs/screenshots/`.

## Files

| File | What it is |
|---|---|
| `dist/StealAnimeEgg_UI_Lab.rbxmx` | Editable ScreenGui model (XML) with all frames + scripts |
| `dist/StealAnimeEgg_UI_Lab.rbxm` | Same model, binary (written by Rojo 7.7's binary serializer) |
| `dist/StealAnimeEgg_UI_Lab_Demo.rbxlx` | Ready-to-play place: baseplate + spawn + the UI in StarterGui |
| `assets/png/atlas/atlas_a/b/c.png` + `assets/png/fx_rays.png` + `assets/png/pattern_*.png` | the **9 images to upload** |

## Option A: Demo place (fastest look)

1. Open `dist/StealAnimeEgg_UI_Lab_Demo.rbxlx` in Studio (File > Open from File).
2. Do **step 3 (images)** below, then press **Play**.
3. Use the yellow **PREVIEW MODE** panel (top-right) to open every menu and switch states.

## Option B: Drop the model into your own place

1. In Studio: right-click **StarterGui** > *Insert from File…* > choose
   `StealAnimeEgg_UI_Lab.rbxm` (or `.rbxmx`). You get `StarterGui.StealAnimeEggUI`
   with a `LabScripts` folder inside. Nothing else in your place is touched.
2. Do step 3, then Play.

## Option C: Rojo (source-controlled workflow)

```bash
rojo serve               # default.project.json  = demo place (StarterGui + baseplate)
# or build files yourself
rojo build package.project.json -o StealAnimeEgg_UI_Lab.rbxm
rojo build default.project.json -o StealAnimeEgg_UI_Lab_Demo.rbxlx
```
`src/gui/*.rbxmx` are generated by `tools/build.js`, and `src/client/*.lua` are the scripts.
To rebuild everything (art, model, preview, dist) run `cd tools && npm install && node render-art.js && node build.js`.

## Step 3: Upload the images (required once)

Roblox cannot load local PNGs, so icons stay blank until they are uploaded.
All icons, portraits and eggs are packed into **3 atlases**, so there are only **9 uploads**.

1. Studio > **View > Asset Manager** > **Bulk Import** > select:
   `assets/png/atlas/atlas_a.png`, `atlas_b.png`, `atlas_c.png`, `assets/png/fx_rays.png`,
   `assets/png/pattern_diagonal.png`, `pattern_dots.png`, `pattern_tiles.png`,
   `pattern_stars.png`, `pattern_hazard.png`.
2. In Asset Manager > Images, right-click each > **Copy Asset ID**.
3. Open `StarterGui.StealAnimeEggUI.LabScripts.AssetIds` and paste each id
   (`atlas_a = "rbxassetid://123…"`).
4. Images now appear in **Play**. To also see them while **editing**, paste
   `src/studio/ApplyAssetIds_CommandBar.lua` into **View > Command Bar** and press Enter
   (writes Image + ImageRect onto the StarterGui copy; undoable).

Until ids are filled, the output shows one warning:
`Image ids not set yet - upload assets/png and fill LabScripts/AssetIds`.

## Testing responsiveness

* Studio > **Test > Device** emulator: try *iPhone 14 landscape*, *iPad*, *1080p*.
* Every top-level frame has a `UIScale` named `AutoScale`; `UIController` sets
  `clamp(min(w/1280, h/720), 0.45, 2)`. Tweak `MIN_SCALE`/`MAX_SCALE` in `UIController`.
* To edit at a specific scale in edit mode, change `AutoScale.Scale` by hand (the
  controller overwrites it at runtime).

## Editing tips

* Every visual layer is a real instance: e.g. change a button colour via
  `…Button.Face.UIGradient.Color`, or the lip via `…Button.Lip.BackgroundColor3`.
* Theme colours for new work: `LabScripts.Theme` (and `docs/DESIGN_SYSTEM.md`).
* Menus are hidden by default. Toggle `Visible` on `ShopMenu` etc. to edit them.
* State frames (egg `StateOwned/StateHatching/StateReady/StateOpened`, index
  `Unlocked/Locked`, carry `Unsafe/Secured`, upgrade `UpgradeButton/MaxLevelButton`)
  are all pre-built. Toggle `Visible` to edit each state.

## Removing the preview system

Delete `PREVIEW_Panel` (frame), `LabScripts.PREVIEW_Controller` and
`LabScripts.PREVIEW_SampleData`. `Main` detects their absence automatically. Then drive the
UI from your game code using the attribute hooks listed in `UI_HIERARCHY.md`
(`UIController:OpenMenu(name)`, `:CloseMenu()`, `:SetTab(button, tab)`,
`.MenuChanged` event).

## Known limitations

* Prices use a generic gem icon (`icon_gem`) as a **sample** premium currency. Swap in the
  official Robux glyph for production.
* The `Egg3D` ViewportFrames are optional (`Enable3D` attribute, off by default). The
  2D egg art is richer than a primitive 3D ellipsoid.
* Fonts are Roblox built-ins (Luckiest Guy, Fredoka One), so nothing to upload.
